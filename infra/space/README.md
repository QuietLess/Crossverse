# CrossVerse

Movie ↔ game recommendations by taste. Add movies, shows or games you love and get recommendations
from the other side (or both), with the reason for every pick.

* Behaviour: Amazon Reviews 2023 (users who rated both movies and games), research use.
* Metadata: TMDB and IGDB. This product uses the TMDB API but is not endorsed or certified by TMDB.
* Source code: https://github.com/QuietLess/Crossverse

The app opens at `/ui/`; the API documentation is at `/docs`. A free Space sleeps after two days
without visitors; the first visit after that takes about a minute.
